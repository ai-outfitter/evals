## Summary  
Outfitter personas act as project‑steering documents that let a team review design changes, code, and documentation from the perspective of a defined user persona—ensuring both human insight and agent alignment.

## Key points  
- Personas consist of a role, biography, and organization.  
- The same individual (e.g., John Doe) can be assigned different roles at various companies.  
- They are used to evaluate how designs, documentation, or code read for that persona.  
- Personas serve as project‑steering docs that guide both human stakeholders and the agent throughout the project.
